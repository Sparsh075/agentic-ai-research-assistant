# 🚀 Agentic AI Research Assistant  
### 🧠 Graph-Based Knowledge & Recommendation Engine

An advanced full-stack AI system that combines **LLMs + Data Structures + Intelligent Recommendations** to go beyond traditional chatbots.

---

## 📌 Overview

This project builds an **agentic AI assistant** that:
- Answers queries using LLMs  
- Extracts meaningful topics  
- Builds a **dynamic knowledge graph**  
- Recommends related concepts using **Graph Algorithms (BFS)**  
- Learns and improves over time  

---

## 🔥 Features

- 🤖 AI-powered responses  
- 🧠 Graph-based knowledge engine  
- 🎯 Smart recommendation system  
- 💾 Memory & context awareness  
- ⚡ Fast API + modern UI  

---

## 🧠 DSA Used

- Graph (DFS/BFS) → knowledge representation  
- Priority Queue → ranking recommendations  
- Hash Maps → fast lookup  
- Sliding Window → behavior tracking  

---

## 🛠 Tech Stack

Frontend: React.js, Tailwind CSS, Vite  
Backend: FastAPI (Python)  
AI: OpenAI API / LLaMA  
Database: MongoDB / Neo4j
